# PlatformIO

Códigos desenvolvidos no [PlatformIO](https://platformio.org/), uma ferramenta de desenvolvimento para sistemas embarcados.

> [!WARNING]
> Ao inserir um novo arquivo de código (e dependências como libs) no projeto, favor inserir o arquivo `platformio.ini` para que qualquer um que queira testar o código no PlatformIO possa fazê-lo sem problemas.
